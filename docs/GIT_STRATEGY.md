# Git Strategy & Conventional Commits

## Branching Model
- `main`: Production releases.
- `develop`: Integration branch for completed module features.
- `feature/<module-name>`: Feature development branches.

## Conventional Commits Structure
- `feat:` New feature for a module.
- `fix:` Bug fix.
- `docs:` Documentation updates.
- `refactor:` Code refactoring without functionality changes.
- `test:` Unit or integration test additions.
- `build:` Build configuration updates.
- `chore:` Maintenance tasks.
